# 03 · 快剪画面语法（30–90 秒）

> 本文的节奏、出处、光敏规矩对所有风格都适用；「配色」「片头」「镜头表」几节写的是 **burst（黄色大色块）** 这一套。其它风格的配色、片头、招牌组件见 `04-风格库.md` 和 `assets/styles/demos/`。

基础是 vertical-science-video 的 pop kit（`P.*`，见那边 `references/02-竖版风格与版面.md`），这里只写短视频多出来的规矩和 `news_kit.js` 组件。

## 节奏

- **每 2–3 秒一个视觉事件**（砸字、卡片、数字、切镜），每镜 2–6 秒。科普片一镜 6–10 秒，这里要快一倍。
- 开口 0.3 秒内画面就有主体；关键数字**比口播早 0.1–0.2 秒**砸出（`w('L03','十倍') - 0.15`）。
- 爆点三件套：`P.boom`（爆炸星＋砸字）＋`P.shakeCam` 短震屏＋爆点音效。白闪 `flash:true` 全片最多 2–3 次、每秒不超过 1 次（光敏安全）。
- 右上角 `P.beat(k, n, at)` 爆点计数，给观众「后面还有」的预期。

## 配色

- 默认科技暗色：底 `C.bgDark #0B0B12`／`C.ink`，强调 `C.hot #FF2E63`（爆点）、`C.elec #2D7FF9`（对比的另一方）、`C.neon #00E5A0`、`C.yel`（荧光笔、数字）。
- 片头标题和反转段用亮底（`C.yel`、`C.paper`）：亮→暗→亮的反差本身就是节奏。
- 一屏强调色 ≤2 个；VS 两方的颜色全片固定（A 永远蓝、B 永远红）。
- 涨跌、价格降了这类：按中文习惯红涨绿跌；「价格砍到 1/10」用 `C.hot` 强调即可，不用绿。

## 片头（0–3 秒）

```js
SCENES.s01 = { draw: P.shot(C.yel, (c, t) => {
  if (t < t0('L01') - 0.1) {
    P.hookTitle(c, t, [
      { s: '英伟达', at: -0.3, size: 230 },                               // 第 0 帧可见（封面）
      { s: '慌了？', at: w('L00', '慌') - 0.1, size: 300, color: C.white, hot: true },
      { s: '价格只要十分之一', at: w('L00', '十分之一') - 0.1, size: 96, y: 1300 },
    ]);
    return;
  }
  P.newsCard(c, 540, 760, t, t0('L01'), { source: '官方博客', date: '2026-10-09', lines: ['某某发布新芯片', 'API 价格降到 1/10'] });
}, { cam: P.shakeCam([w('L00', '慌') - 0.1]) }) };
```
- 标题最多 3 行：主语（墨色）→ 暴论词（大、强调色、爆炸星）→ 一行小字补钩子。封面字取前两行。
- 标题撤下＝`t0('L01') - 0.1`，台头 `P.HEAD_FROM` 默认就是这个时刻。

## 组件速查（news_kit.js）

| 组件 | 用途 |
|---|---|
| `P.hookTitle(c, t, lines)` | 片头三行暴论标题；行距按字号自动算；`hot` 行 ≤2 字衬爆炸星，更长衬横贯斜切色带（星盖不住长字，白字会落在亮底上） |
| `P.newsCard(c, x, y, t, at, {source, date, lines})` | 「发生了什么」资讯卡：来源胶囊＋日期＋逐字打出的标题 |
| `P.quote(c, x, y, t, at, {text, who})` | 真实原话（换行用 `\n`），写全出处 |
| `P.vs(c, t, at, {left, right, lsub, rsub, winner})` | 斜切对决，中间 VS 弹入，输家变暗 |
| `P.specs(c, t, at, rows, {nameA, nameB})` | 参数对比条（每行按两者最大值归一），数值写在条外 |
| `P.boom(c, s, x, y, t, at, {flash})` | 爆点结论砸字：≤2 字或纯数字衬爆炸星，更长的衬横贯色带（自动判断） |
| `P.burst` / `P.shakeAt` / `P.shakeCam([...])` / `P.flash` | 单独的爆炸星、震屏、白闪 |
| `P.beat(c, t, k, n, at)` | 「爆点 k/n」计数胶囊 |
| pop kit 原有 | `P.slam`、`P.rise`、`P.pop`、`P.slide`、`P.card`、`P.pill`、`P.stamp`、`P.marker`、`P.bars`、`P.waffle`、`P.count`、`P.src` |

## 镜头表（60 秒样例，约 12 镜）

| 镜 | 口播 | 画面 |
|---|---|---|
| s01 | L00 暴论 → L01 事实 | 黄底三行标题 → 资讯卡 |
| s02 | L01 关键数字 | 黑底大数字砸入＋爆炸星 |
| s03–s05 | 爆点 1 | VS 对决 → 参数对比 → 结论 boom |
| s06–s08 | 爆点 2 | 柱状图／原话卡 → boom |
| s09–s10 | 反转 | 底色反转（黄/米白），一句大字＋印章 |
| s11 | 金句＋互动 | 金句砸字＋「你会换吗？评论区」胶囊 |

转场：章内硬切或 `push` 上滑 0.3s；换爆点用 `bands` 0.45s；反转段可以 `fillZoom` 冲进爆炸星。

## 出处与免责

- 每个数字镜头底部 `P.src('来源：……')`（≥24px）；片尾不做长出处卡（短视频没人看），出处放进 `发布文案.md` 和 README。
- 传闻类内容在画面上写「据传」「未官宣」。
