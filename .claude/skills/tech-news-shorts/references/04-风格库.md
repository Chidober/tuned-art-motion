# 04 · 风格库：六套视觉皮肤，轮着用

为什么要换：同一个账号连着三支都是「黄底砸字＋爆炸星」，观众第二支就开始划走——形式本身不再有冲击力。黄色大色块这套（burst）效果很好，保留，但它只是六套之一。

每套风格是一个皮肤文件 `assets/styles/<风格>.js`，建工程时拷成 `<film>/style.js`，在 `news_kit.js` 之后加载。它会整体替换：配色（`P.S`）、底纹（`P.bg`）、片头（`P.hookTitle`）、资讯卡、引语、结论（`P.boom`）、爆点计数（`P.beat`）、台头、字幕条，并带几样**招牌组件**。转场和配乐速度由 `new_short.sh` 按风格写进段落表和 `score.py`。

看样子：`python .claude/skills/tech-news-shorts/scripts/style_preview.py` → `projects/_style_demo/风格对照.jpg`（每行一种风格，4 帧）。每种风格的样片代码在 `assets/styles/demos/<风格>.js`，写镜头时照着抄。

## 怎么选

1. **先查日志** `projects/.shorts_log.tsv`：最近两支用过的风格不选（用户点名除外）。`new_short.sh` 不给 `--style` 时会自动挑最久没用的那个，用过了会警告。
2. **再看题材气质**：下表「适合」一列。同一条新闻往往两三种都合适，挑和上一支反差最大的。
3. **最后看素材形态**：一串数字 → dashboard / keynote；有人物发言 → desk；有代码、参数、开源 → terminal；吃瓜、生活影响、盘点 → zine；争议、反转、情绪 → burst。

## 每套风格的规矩（皮肤管不到、要靠镜头代码守住的）

- **burst**：亮→暗→亮的反差是节奏；白闪全片 ≤3 次。详见 `03-快剪画面.md`。
- **desk**：一切都是**水平运动**（横推、跑马灯），不弹跳、不旋转、不震屏；人名一定配 `P.lowerThird`；台头下的跑马灯 `P.TICKER` 写 2–3 条事实（不是口号），全片固定。反转段用 `S.alt` 浅底。
- **terminal**：所有文字都是「打出来」的（`P.type`/`P.term`），没有砸入；数字对比优先用 `P.diff`（旧版红、新版绿）；震屏只做横向抖格。英文命令可以写，但要让不懂代码的人也看懂（命令后面紧跟中文结果行）。
- **keynote**：**一屏只说一件事**，留白 ≥50%；不砸、不弹、不震，一律 `P.reveal` 浮现（0.7s）；数字用 `P.bigNum`（Inter），中文结论用 `P.boom` 渐变字；反转段切到 `S.alt` 浅灰白底，形成「发布会换场」的感觉。节奏比其它风格慢：每镜 3–5 秒。
- **dashboard**：每个数字都要有容器（面板、仪表、环、折线），不要裸数字；重点数字用 `P.lockOn` 锁定；颜色语义固定：青＝中性数据，红＝警示/超标，黄＝高亮，绿＝正向。
- **zine**：动画按 12fps 定格（`P.stop(t)`），元素「啪」地贴上而不是平滑飞入；每镜至少一处手写批注（`P.hand`，LXGW 文楷）或红笔圈画，像博主在桌上拆解；字幕条保持白纸黑字，别用手写体（可读性）。

## 通用写法（换皮肤不用改的部分）

- 颜色一律用 `P.S.*`：`bg` 主底、`alt` 反转段底色、`fg` 主底上的字、`ink` 亮底上的字、`mute` 次要字、`hot` 爆点/警示、`cool` 对比方、`hi` 高亮、`ok` 正向、`panel` 卡片底。`P.DARKIDS` 只影响 burst 的台头配色，其它风格的台头自己适配。
- 通用组件各风格都有：`P.hookTitle`、`P.newsCard`、`P.quote`、`P.boom`、`P.beat`、`P.vs`、`P.specs`、`P.src`，以及 pop kit 的 `P.rise`、`P.pop`、`P.slide`、`P.text`、`P.count`。`P.slam`、`P.stamp` 在 keynote/zine 里被换成了浮现/手写版。
- 数字和英文用 `P.vtext(c, s, x, y, {size, weight, fam: 'Inter'|'RobotoCondensed'})`；中文仍是 `P.BLACK/HEAVY/BOLD/MED`（黑体子集，缺「≠ ≤ ω ζ」等字，见踩坑清单）。手写中文用 `P.HAND`（霞鹜文楷）。
- 招牌组件只在自己的风格里有，换风格时要换成对方的招牌组件，而不是把 burst 的爆炸星硬带过去。

## 加一套新风格

1. 抄一个最接近的 `assets/styles/*.js`，改 `P.S` 和招牌组件；台头、字幕条要能读（白底黑字或深底白字，字号 ≥50）。
2. 写 `assets/styles/demos/<新风格>.js`（4 镜 × 3 秒，示例文字），在 `style_preview.py` 的 `TR` 和 `new_short.sh` 的 `ALL`/`case` 里加上它。
3. 跑 `style_preview.py --styles <新风格> --at 1.5,3.1,4.9,6.2,8.2,11.2`，看片头第 0 帧、转场中间帧、字幕条。
4. 在上表加一行。

## 注意

- 风格皮肤只写**通用**版式：desk 不仿任何真实电视台的台标、配色组合、栏目名；keynote 不仿任何公司的发布会字体排印和页面；terminal 的命令是虚构的，不冒充真实产品的界面。
- 片头第 0 帧必须完整可见：burst/zine `at: -0.3`，desk `-0.5`（横推 0.45s），keynote `-0.8`（浮现 0.7s），terminal 打字行 `-1`。
- 光敏安全不分风格：白闪、像素化、RGB 错位每秒 ≤1 次。
