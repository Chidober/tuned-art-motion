# 05 · 叙事结构与钩子：换的不只是皮肤

只换配色，片子还是「标题 → 资讯卡 → 爆点 1/2/3 → 反转 → 提问」，熟悉的观众三秒就认出来。每支片要定三件事，写进 `new_short.sh --style … --structure … --hook …`，日志会记下来：

- **风格**：见 `04-风格库.md`。
- **叙事结构**：这一节。
- **钩子形式**：下一节。

**轮换规则**：查 `projects/.shorts_log.tsv`。
- **风格**：和最近两支都不同。
- **结构、钩子**：至少有一个和上一支不同。
- **例外**：用户点名的不受限制。

## 叙事结构（选一个，写稿前定）

| 结构 | 骨架（30–90 秒） | 适合 | 推荐风格 |
|---|---|---|---|
| **三爆点** | 钩子 → 事实 → 爆点 1/2/3（`P.beat`）→ 反转 → 提问 | 一条新闻有 2–3 个独立看点 | burst、dashboard |
| **真假核查** | 钩子念原说法 → 逐条打分：✔ 属实／△ 有条件／✘ 夸大 → 结论「几分真」 | 网传说法、营销文案、标题党新闻（固态电池那条就适合） | desk、terminal |
| **倒计时 Top N** | 「这次发布最值得看的 3 件事」→ 第 3 → 第 2 → 第 1（最猛的放最后） | 发布会、年度盘点、一次放出很多东西 | keynote、zine |
| **一个数字讲到底** | 钩子砸一个数 → 它怎么来的 → 和什么比 → 它意味着什么 → 反问 | 价格、参数、融资额、跑分 | keynote、dashboard |
| **时间线** | 「X 年前……」→ 3–4 个节点 → 今天 → 下一步 | 有历史纵深的事（制程、模型代际、监管演变） | dashboard、desk |
| **你会受什么影响** | 钩子问观众（「你的手机要涨价？」）→ 事实 → 对你的 2–3 个影响 → 现在该怎么办（不给投资建议） | 消费电子、政策、平台规则变化 | zine、desk |
| **正反对线** | 支持方最强论点 vs 反对方最强论点，各 2 回合 → 我的判断（标明是判断） | 争议、学界/业界两极 | burst（`P.vs`）、terminal（`P.diff`） |
| **拆解** | 「它到底是怎么做到的？」→ 一张原理图分 3 步 → 代价是什么 | 技术突破、论文、新架构 | terminal、keynote |

各结构的共同点：
- 开头 3 秒要有冲突或悬念。
- 中段每 2–3 秒有新视觉事件。
- 结尾要有态度或提问。
- 事实底线照旧，见 `01-爆点写作.md`。

**真假核查的画面**：每条说法一个镜头，上面是原话（引号），下面盖章。
- desk：红／绿条。
- terminal：`P.diff` 红绿行。
- zine：手写批注。
- ✔ ✘ 不在黑体子集里，用「√ ×」（子集里有）、路径画，或者直接写「属实／夸大」。

## 钩子形式（第 0 帧到 3 秒）

| 钩子 | 例 | 画面 |
|---|---|---|
| **三行暴论砸字** | 「372 项数学成果 / 数学家 / 吵翻了？」 | `P.hookTitle` 三行（burst 默认） |
| **一个巨型数字** | 「9999」→「它凭什么卖这个价？」 | 第 0 帧就是满屏数字（`P.bigNum` / `P.board` / `P.sticky`），标题小字在下 |
| **原话打脸** | 「“充电 10 分钟满电”——真的吗？」 | 引语卡＋问号印章；原话要真实，写出处 |
| **反问观众** | 「你的下一部手机，可能要贵 500？」 | 问句大字＋观众相关的图标/价格 |
| **对比分屏** | 左「999 元」右「9999 元」 | `P.vs` / `P.compare` / `P.diff` 第 0 帧就在 |
| **倒计时/清单** | 「3 件事，第 1 件最离谱」 | 大号「3」＋三个空位，后面逐个填 |
| **结论先行** | 「先说结论：没那么快。」 | 结论大字＋「为什么？」小字 |
| **时间跳切** | 「2019 年它还是个笑话，今天……」 | 年份大字从旧到新滚动 |

钩子的规矩：
- L00 ≤16 字，0.3 秒开口。
- 第 0 帧必须有完整的冲突信息（封面截图就是它）。
- 钩子提出的问题，片子里要回答。

## 写进日志

`new_short.sh <slug> <film> "<标题>" --style desk --structure 真假核查 --hook 原话打脸`。如果写稿时改了结构或钩子，回头改 `projects/.shorts_log.tsv` 的最后一行，下一支片就能照着避开。
