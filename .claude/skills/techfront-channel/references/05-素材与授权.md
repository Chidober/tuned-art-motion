# 05 · 素材与授权（B-v1 的做法）
## 原则
- 只用和内容**直接相关**、且**授权查得到**的素材；查不到授权就不用。
- 优先顺序：公有领域、CC0 → CC BY → CC BY-SA（要注明，见下）。
- 不用：NC（频道有商业属性）；ND（推拉、裁切都算改编）；没有写授权的官方图（例：Anthropic 博客配图）；任何真实网页截图或 logo。
- 素材只下载到 `projects/<slug>/素材/raw/`。下载前先在 `素材来源.json` 里记好授权元数据。

## 流程（Wikimedia Commons）
1. 搜索：Commons API `generator=search&gsrnamespace=6`，关键词加 `filetype:video` 可以只搜视频。请求太快会被限流，失败了就隔一会儿逐条重试。
2. 读授权：`prop=imageinfo&iiprop=extmetadata`，取 `LicenseShortName / LicenseUrl / Artist / Credit / AttributionRequired`；公有领域的，再看文件页模板（例 `{{PD-user}}`）。
3. 选清晰度：视频有 `videoinfo&viprop=derivatives` 转码版（240p–1080p）。几秒钟的 b-roll 不值得下几百 MB，可以用 480p 放进小窗口。
4. 下载：用 Python（`scripts/commons_assets.py`）。`.venv` 里的 ffmpeg 不认 HTTPS 证书，不要拿它直接读远程地址，也不要关掉证书校验。
5. 看内容：抽帧拼成联系表看一遍。
   - 剔除：可识别的私人面孔（B 版机房视频里的主持人）、街道名和路牌、敏感场面（抗议、执法冲突视频）、和内容无关的品牌；
   - 需要时裁切，例如去掉店招，并在署名里写 "(cropped)"。
6. 用到片子里：抽帧或单帧序列放进代码工程的 `foot/`，由画面代码播放；画面上署名（作者 / Wikimedia Commons / 授权）。通用素材标 "illustration"，以免被理解成当事方的实景。
7. 登记：`sources.md` 素材表写清楚：时间点（母版和各平台版）、文件页链接、作者、授权（附链接）、用法（截取段、速度、裁切）。发布简介里也列一遍署名。

## 署名格式
画面：`Photo: <作者>, Wikimedia Commons, CC BY 4.0`、`Video: <作者>, Wikimedia Commons, CC BY 3.0`、`(cropped)`。字体用 `Inter`，因为黑体子集缺 ý、ç 等字母。
简介：`"<标题>" by <作者>, <授权> <授权链接>`。

## CC BY-SA 的注意点
推拉、裁切后的图属于改编，按 BY-SA 署名并写明授权。整支视频是否因此必须用 BY-SA 发布，有法律上的不确定性：交付时写进遗留问题，让用户决定；想避开就换成 CC BY 或公有领域素材。
