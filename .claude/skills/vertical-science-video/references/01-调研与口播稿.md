# 01 · 调研、事实核对与口播稿

## 调研路径

1. **先找一手来源**，二手只当线索：
   - 诺贝尔奖：nobelprize.org 的 press release、Popular information（科普背景，最适合当稿子骨架）、Advanced information。WebFetch 会 403，用内置浏览器（`preview_start` 打开后 `get_page_text`）。
   - 研究数据：论文摘要原文（IDEAS/RePEc、SSRN、期刊页、作者主页）。转述文章（博客、CXO Advisory、媒体）常改口径，例如巴西日内交易论文摘要写的是「97% 亏钱」，转述成了「只有 3% 平均日净收益为正」。
   - 历史数据：数据源本身（Damodaran、S&P DJI 等），并记下它的口径。
2. **人名**：中文译名查中文媒体或维基，日本人名查日文维基的汉字（硤合憲三 → 简体「硖合宪三」）；生僻字确认在字体子集里（`U.assertGlyphs`）。
3. **素材**（图片、视频）：Wikimedia Commons API 查 `extmetadata` 的许可、作者、描述。读描述！光遗传学那支片的一段斑马鱼视频描述写着「野生型对照组」，当示例就讲反了；一段神经元视频是自发活动而不是光刺激。下载前先问用户，列出文件名、来源、大小、许可。可以按 zip 偏移、缩略图宽度只取需要的部分。

## 事实表（写稿前建好）

| 说法 | 数值 | 口径 | 出处（链接） |
|---|---|---|---|
| 标普 500 长期回报 | 9.94%/年 | 1928–2024，含分红，**几何（复合）**；1957 年前为前身指数 | Damodaran |
| 持有 20 年无亏损 | 0 次 | **名义**、含分红；1919 年起 | Crestmont |

口径写错是审片最常抓的错：名义/实际、复合/算术、样本（谁、哪年、多少人）、「平均是赚的」≠「赚了钱」。

## 稿子结构（3–5 分钟，1000–1300 字）

- **L00 片头人声**：把标题问题念出来（「炒股，到底是不是赌博？」），`gapAfter` 0.5。
- **第 1 章钩子（20–30 秒）**：常见说法 → 「这话只对了一半」/ 一个反差 → 「今天把这笔账算清楚」。
- **中间 4–6 章**：每章一个论点＋一个能画出来的证据（数字、对比、机制）。诺奖片按官方科普的「思路链」讲（谁在哪一年补上了哪一环）。
- **反方/边界一章**：什么情况下结论不成立（「这一部分确实更像赌博」）。
- **结论**：一句话答案＋三个可记住的词。
- **声明**：投资、医疗类加免责；历史数据加「不代表未来」。

写法：
- 短句，口语，每句一个信息点；因果句先自问「依据是什么」（物理那支片把「压力把气泡挤出冰外」写错了，实际是气泡变成空气水合物晶体）。
- 每句都要能画：写稿时就在脑子里放镜头。
- 有争议的引语不确定出处就不署名。

## 口播稿 JSON 字段

```json
{"id": "L09", "ch": 3, "text": "字幕上显示的字", "say": "实际念的字（可选）", "cut": ["手工", "断行（可选）"], "gapAfter": 0.6}
```
- `ch`：章节开头（章节间停顿 `chapterGap`，配乐强度按章节走）。
- `say`：念法和字面不同时用（口语数字「两块七」、生僻字换同音字、「标普五百」）。镜头锚点 `w('Lxx', '词')` 找的是**念的字**，所以锚点要写 say 里的字（`w('L07','峡合')`）。
- `cut`：字幕手工断行，拼起来必须等于 text。凡是有人名、带小数点或百分号的数字、长专有名词的句子，打印字幕检查一遍。
- `gapAfter`：句后停顿。句末关键词要打字或计数时加长（0.5–0.9），别硬加速动画。
