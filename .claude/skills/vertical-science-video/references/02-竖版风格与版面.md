# 02 · 竖版风格、版面与镜头写法

## 选风格：看口播在干什么

先读 `06-选语法与风格.md`：语法和艺术风格要按选题选，出标题图给用户确认后才往下做。下表只列本 skill 已经有现成 kit 的三种；其它语法（白板、3b1b、发布会、讲解员、故事角色）和 35 种艺术风格在仓库 `references/09`、`references/风格配方/` 里。

| 内容 | 风格 | kit | 已有成片 |
|---|---|---|---|
| 数字、比较、「是不是」「值不值」、经济/社会话题，要抓眼球 | **动态文字＋数据图**（y5＋t3）：每章整屏底色，主词弹簧砸入，柱状图、百格图、计数 | `pop`（`assets/kits/pop_kit.js`） | `projects/stock_gamble/` |
| 有历史、人物、文献、实验的「思路链」（诺奖、科学史） | **Vox 拼贴**（y2）：纸纹桌面、网点历史照片、黑胶带标签、红笔、荧光笔、印章、红线时间轴；元素 12fps 一拍二 | `collage`（`collage_kit.js`＋`collage_draw.js`） | `projects/nobel2026_chirality/` |
| 讲尺度、讲「里面是什么」、太空/细胞/粒子 | **Kurzgesagt 扁平**（y1）：深色、发光、相机穿行尺度 | 目前只有横版：`projects/nobel2026_icecube/代码工程/nobel/`、`nobel2026_optogenetics/代码工程/opto/`，竖版要按下文版面改坐标 | 物理、医学两支（横版） |

## 竖版版面（1080×1920）

| 带 | y | 放什么 |
|---|---|---|
| 台头 | 70–190 | `window.HEADER = {tag, title, note}`：左上标签＋片名，下面一行常驻小字（如「不构成投资建议」）。只占左半边，右上角留给 TechFront 水印（y≈96） |
| 内容 | 230–1480 | 一屏一个焦点；主图别全挤在上半部，1000–1480 也要用上 |
| 字幕条 | ≈1540–1640 | kit 的 GLOBAL_OVERLAY 画（pop：深色圆角条；collage：黑胶带纸条）。内容别进这条，慢推镜头会把底部元素推下来，留 60px 余量 |
| 平台界面 | 1700–1920 | 只放底色 |

出处小字 ≥24px（`P.src` 放不下会先缩再折行），放在 y≈1450。

## 动态文字（pop kit）

```js
// 段落表：U.setStage(1080,1920)；SCENE_LIBS = ['<film>/kit.js', '<film>/shots_a.js', ...]
const C = P.C, w = P.w, t0 = P.t0;
['s03', 's04'].forEach(id => P.DARKIDS.add(id));          // 深底镜头：台头自动换浅色
SCENES.s04 = { draw: P.shot(C.navy, (c, t) => {          // 底色＋点阵漂移＋镜头微漂
  const a = t0('L04');
  P.rise(c, '每押 100 块', 540, 380, t, a + 0.1, { size: 96, fam: P.BLACK, color: C.white, align: 'center' });
  const b = w('L04', '两块七') - 0.25, v = P.count(t, b, 0.9, 0, 2.7);
  if (t >= b) P.slam(c, '-' + v.toFixed(1), 540, 860, t, b, { size: 330, fam: P.NUM, color: C.down, from: 1.4 });
  P.slide(c, t, a + 1.2, 540, 1250, (g) => { P.card(g, 0, 0, 900, 300); /* … */ });
}) };
```
- 入场：主词 `P.slam`（弹簧 1.7→1）、辅句 `P.rise`（字槽升起）、图标 `P.pop`（backOut）、卡片 `P.slide`（下方滑入带旋转回正）、`P.stamp` 印章、`P.marker` 荧光笔、`P.pill` 胶囊。
- 图表：`P.bars`（从 0 起、数值诚实、逐根长出）、`P.waffle`（10×10 百格，`colOf(i)` 着色）、`P.count`（计数）。道具：`P.coin`、`P.wheel`（欧式轮盘）、`P.chip`、`P.jar`、`P.company`、`P.person`。
- 底色：每章一个（黄 `#FFD23F`→藏青→米白→珊瑚→黑…），强调色一次只用一个。章内转场 `push` 上滑 0.4s，换章 `bands` 色带（最后一条＝新章底色）。
- `P.NUM`（Anton）只有拉丁字符和数字：「左 50%」这种中英混排整串用 `P.BLACK`。

## Vox 拼贴（collage kit）

```js
const C = K.C, w = K.w;
SCENES.c08 = { draw: K.shot((c, t, lt) => {               // 纸纹桌面＋每秒 1% 慢推
  K.photo(c, 'chiral/img/01_巴斯德.jpg', 330, 640, 440, 560, { r: -0.03, caption: '路易·巴斯德' });
  K.credit(c, 'Paul Nadar 摄 · 公有领域', 110, 1040);
  K.year(c, '1848', 640, 360, { size: 84 });
  K.slide(c, t, w('L10', '酒') - 0.2, 800, 640, 0.03, (g) => { K.card(g, 0, 0, 400, 360, { lined: true }); /* … */ });
  K.circle(c, 540, 1190, 250, 240, t, w('L10', '镜像'));  // 红笔圈，一拍二描出
}, { push: 0.01 }) };
```
- 元素层全部 12fps 步进（`K.S(t)`），相机 60fps 平滑：「相机滑、元素顿」是拼贴的手工感。
- 打字 `K.type`（13 字/秒）、荧光笔 `K.hl`、红笔 `K.circle/K.under/K.arrow/K.check/K.cross`、`K.stamp`、`K.slam`、黑胶带 `K.tag`、网点照片 `K.photo`（图片放 `代码工程/<film>/img/` 并写进 `EXTRA_ASSETS`）。
- 长镜头滚动（时间轴）用 `K.shot(draw, { cam, band: true })`：内容只在台头与字幕之间显示、上下渐隐，卡片不会从台头和字幕底下穿过。
- 全片硬切，切点卡在句读。

## 竖版＋横版一起出（同一条口播、同一套镜头）

用户要「一个竖屏一个横屏」时不要写两套镜头（安迪-比尔定理那支，`projects/andy_bill/`）：
- pop kit 的尺寸读 `window.STAGE`（`P.V` 是否竖版、`P.CX` 中线、`P.SUB_Y` 字幕条、`P.SRC_Y` 出处行），字幕条、台头、出处、淡出两版都对。
- 镜头画在**槽位**的局部坐标里：`P.in(c, 'A'|'B'|'C'|'head'|'foot', g => …)`，原点＝槽位中心。A、B 是两块 1000×520 的内容区（竖版上下叠，横版左右排、缩 0.88）；C 是一整块 1000×600；head 是本镜标题行，foot 是底部一行。写镜头时按局部坐标 ±500 × ±260（C 为 ±300）摆，两版自动对。
- 只有片头标题按 `P.V` 分开写坐标（横版标题要更扁）。
- 横版段落表 `eras_<film>h.js` 只有两行：`U.setStage(1920, 1080); window.STAGE_SET = true;` 再同步加载竖版段落表（竖版段落表首行写 `if (!window.STAGE_SET) U.setStage(1080, 1920);`）。横版目录 `<film>h/` 里放一份 `timing.json` 副本（渲染脚本按它读时长）。
- 渲染：`SIZE=1920x1080 OUT=全片_横版_无声.mp4 bash render_parallel.sh projects/<slug> <film>h`；收尾：`SILENT=渲染/全片_横版_无声.mp4 bash finish.sh ...`；关键帧：`overview.py ... <film>h --size 1920x1080 --stills ...`；成片总览用竖版的 film 名读镜头表（`overview.py ... <film> <横版成片.mp4>`）。
- 两版的关键帧都要看：横版左右排后，「左卡右戳」容易叠到槽位外，竖版没事的横版不一定没事。

## 片头（两种风格通用）

- 第 0 帧就有标题主词：`P.slam(..., t, -0.3)`（起点设成负数，第一帧已经落定；起点 0 的话第一帧透明）。
- 标题三段式：主词（大、墨色）→ 问句胶囊（「是不是」）→ 反差词（大、强调色、带旋转回正），每段的出现时刻锚在 L00 人声的那个字上；最后一行小字（「一次算清这笔账」），别写具体分钟数（容易和实际时长对不上）。
- 标题撤下＝`t0('L01') - 0.1`，`P.HEAD_FROM = t0('L01') - 0.15` 让台头接上。

## 节奏规矩

- 每镜开口 0.5 秒内有主体；关键数字可以比口播早出现（先出主数字，坐标轴、格子作为第二拍），不要先铺空框架再慢慢填。
- 句末关键词离切点 <1 秒：给那句 `gapAfter`，或把元素锚到更早的词。
- 大面积闪烁 ≤3 次/秒（光敏安全）。
- 示意图的方向必须和口播一致：写完模拟/示意，自己问「画面说的是什么结论」。
