# 03 · 踩坑清单（四支片的返工原因）

写代码前扫一遍；新踩的坑加在对应小节末尾，写清日期、现象、原因、改法。

## 事实与口径

- **示意图画反**（股票片 s05）：「押红 1000 次」的累计盈亏路径多数停在本金线上方，等于说「多数人押轮盘赚了」。改成「平均每次盈亏收敛到 −2.7%」，这才是大数定律的正确口径，并在画面写「示意」。
- **转述改了口径**：巴西日内交易，转述写「只有 3% 平均日净收益为正」，论文摘要原话是「97% 亏钱」。数字只从原文取。
- **机制和例子对不上**：「输家的钱先被抽成」是彩池/扑克的机制，轮盘是赌场当对手、靠赔率少给一份（公平 36 倍只赔 35 倍）。
- **论文没说的因果**：Barber & Odean 把差距归因于交易成本和频繁换手，不是「追涨杀跌」。
- **口径没写**：年化回报写「复合」；20 年无亏损写「名义、含分红」；「零和」指的是相对大盘的超额收益（跷跷板标「跑赢/跑输大盘」）。
- **科学因果写错**（物理片）：「压力把气泡挤出冰外」→ 实为高压下变成空气水合物晶体；「能量高所以来自太阳系外」漏了真正依据（事件数远超大气本底）。
- **素材描述不读就用**（医学片）：野生型对照组被当成光遗传学示例；自发活动的钙成像被放在「蓝光一照就放电」处。
- **机构名不一致**：官方新闻稿和论文署名对不上时，干脆不写机构。

## 画面

- **空屏**：3–5.5 秒只有空坐标轴或一个小标签（审片两次都抓）。开口 0.5 秒内出主体。
- **字没打完/数没计完就切走**：句末关键词离切点太近 → `gapAfter`。
- **白板版的「拉远看全板」一闪而过**（2026-10-10 安迪-比尔定理白板版）：句后只留 1.9 秒，拉远 1.5 秒、推回 1 秒，全板只静止 0.6 秒，还被下一句字幕压住。改成：拉远那句 `gapAfter` ≥3 秒，全板静止 ≥1.5 秒，缩放留 12% 边距。
- **手写字没写完就切页**：句末才开始写的字（「约 1000 倍」），写完只剩 0.1–0.2 秒。`board_kit.js` 的 `B.END` 让每页的字在切走前 0.35 秒写完；还不够就给那句加 `gapAfter`。
- **英文版开头没标题**（2026-10-09 诺奖物理、医学英文版）：照搬了中文横版「冷开场、片名在第一章末」的结构。英文版第 0 帧必须有片名，见 `05-英文版.md`。
- **第 0 帧空白**：砸字起点 0，第一帧透明度 0 → 起点设 -0.3。
- **元素顶到台头/压字幕条**：相机推近或慢推把内容推出内容带；长镜头滚动用 `band:true`。
- **标签压在线上**：图表的标签放在线的下方或留白处，不放在线的终点。
- **百格图数字压说明**：大数字和说明分开摆（数字在左、说明在右，或上下两行）。
- **两张卡片位置互换**（「次亏损 0」）：数字在前、说明在后。
- **长出处小字出画**：`P.src` 会缩字号再折行；片尾出处卡每行 ≤25 字。
- **自动断行拆人名和数字**（「卡 / 冈」「1 / 928 年」）：口播稿写 `cut`。
- **颜色语义冲突**：涨跌红绿与左右手红黑不要在同一支片里混用含义。

## 字体与字形

- 黑体子集是 GB2312：全角「＝」、真减号「−」、「≠」、希腊字母不在里面 → 改写成文字或半角；启动时 `U.assertGlyphs` 查，缺字会让渲染非零退出。
- Anton 没有中文：中英混排数字整串用黑体。
- 繁体人名（硤）先转简体（硖）再查子集。
- 希腊字母 ω、ζ 也不在子集里（AI 数学短片踩到 ω）：写成「指数」「zeta」。
- 「≠」「≤」也不在（固态电池短片）：写「不是」「以内」。
- 全角「＝」同样不在（安迪-比尔定理片差点用上）：写「就是」「才是」。

## 引擎与工具

- 竖版：段落表第一行 `U.setStage(1080, 1920)`；`render.py`、`qa.py` 都加 `--size 1080x1920`；`lib/kit.js`、`toon.js`、`post.js`、`render.js` 还写死 1920×1080，竖版别用它们的整屏函数。
- 渲染、总览前先 `source .venv/bin/activate`：它设了 `PLAYWRIGHT_BROWSERS_PATH`，只把 `.venv/bin` 加进 PATH 会报找不到 Chromium。
- 竖横两版共用一套镜头时（2026-10-10 安迪-比尔定理）：`render_parallel.sh`、`overview.py` 原来写死 1080x1920、写死 part_*.mp4，横版会覆盖竖版的分段 → 已加 `SIZE`/`OUT`、`--size`；`score.py` 原来 glob 第一个 `eras_*.js`，有两个段落表时可能读到只有两行的横版 → 写死读竖版段落表。
- 来源小字 `P.src` 的 y 别超过 ~1470，否则 qa 报进字幕带（`--sub-band 0.78`）。
- zsh 循环不按空格拆 `"0 66"`：并行渲染用脚本（bash）。
- qa 很慢（30 镜约 25–60 分钟），且测的是启动时的代码：改了代码就停掉旧的 qa。
- `DG.mix` 返回 rgba 串，不能再喂给 `DG.mix`/`TOON.glow`。
- 本地 http 服务要多线程（已改），否则偶发「RIG is not defined」。
- 大面积闪烁超过 3 次/秒有光敏风险（医学片 5Hz 蓝光改成 2Hz 正弦）。

## 音频与配音

- **头 3 秒没人声**（股票片第一版）：`LEAD = 0.6` ＋ L00 念标题。
- **AAC 抬峰值**：混音 −1.5 dBTP，成片测出 +0.65 → loudnorm TP −2.5 ＋ alimiter。
- **曼波（GPT-SoVITS）在 Mac 上**：
  - `jieba_fast`、`pyopenjtalk` 编不过（编译链和 SDK 不匹配）：用 `shims/jieba_fast`，日语/韩语不装。
  - torchaudio 新版要 torchcodec：固定 torch/torchaudio 2.7.1。
  - fast_langdetect 默认去下 126 MB 大模型：固定用包内 lite 模型。
  - 英文单词要 nltk 的 `averaged_perceptron_tagger_eng`。
  - 这些都已在 `local_tts/setup.sh` 处理。
- **口语数字**：「2块7」会念成「二块七」→ `say`「两块七」。
- **火山引擎凭据**只写在 `projects/.env`（gitignore），不在对话里要 key、不打印。

## 流程

- 下载任何文件（素材、模型）先问用户，列文件名、来源、大小。
- 用户说「不需要再修改」的片子，之后不再动它。
- 交付时说明 1080p 超过 30 MB 只能在桌面打开，另发 720p 预览。
