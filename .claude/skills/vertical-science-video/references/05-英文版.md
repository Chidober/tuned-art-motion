# 05 · 给做好的片子出英文版（横版、竖版都行）

第一次用：2026 诺奖三支（物理 / 生理学或医学 / 化学），2026-10-09。中文版的任何文件都不动（物理那支用户说过不再改，英文版是另起的一套文件）。

## 为什么用表格，不手改

画面文字（每支 130–200 条）和「镜头动作挂在口播哪个词上」的锚点（每支 75–90 个）都写死在镜头代码的字符串里。手改几百处一定漏；表格化后：
- 漏译的字串 build 直接报错；
- 没映射上的锚点渲染时 `console.error`，render.py 判失败——不会悄悄错位。

## 开头必须有标题（硬性要求）

英文版的观众多半是在 YouTube 等平台上划到的，不认识中文版。第 0 帧到前 3 秒必须出现完整的英文片名，规则同中文竖版的片头钩子：第 0 帧可见，0.6 秒内开口，可以作为封面截图。
- **2026-10-09 三支诺奖英文版的教训**：物理（21 秒才出片名）、生理学或医学（36 秒才出）直接沿用了中文横版「冷开场 → 片名在第一章末」的结构，英文版开头没有标题。化学那支中文版本来就有 3.6 秒片头标题卡，英文版跟着有。用户指出后，这一条写成了规则；已经交付的两支先不重做。
- **做法**：
  1. 中文版有片头标题卡的，翻译后检查字宽（竖版标题行 ≤14 个字符，或者缩字号）。
  2. 中文版没有的（横版冷开场），给英文版加一个片头标题镜，原片照常接在后面：
     - `音频_en/tts.py` 的 `LEAD` 设 3.0–3.6s，空出时间；
     - 在 `eras_<film>_en.js` 的 `SHOT_LIST` 最前面插一镜 `['t00', null]`，第一镜改成从 L01 开始，即 `['n01', 'L01']`；
     - 标题镜用片中已有的标题函数（如 `N.title`）、主角图形和该片配色，写在 `<film>_en/title.js`，加进 `SCENE_LIBS`；
     - 配乐给片头一记重音（`score.py` 的 SLAMS 或等效音效）。
  3. 原片里第一章末的片名镜头保留不保留都行，保留时改成小一号的回扣，不要和片头重复成两次大标题。
- **检查**：关键帧里加 0 秒、1.5 秒两帧，确认片名完整可读，不是逐字打到一半。

## 填表的规矩

- **script.json**：英文口播。
  - 声音：edge-tts 英文多语种声音，`en-US-AndrewMultilingualNeural`、`AvaMultilingualNeural` 或 `EmmaMultilingualNeural`，`rate` 设 `+6%`。英文比中文长约 15–25%，镜头时长跟着口播自动走。
  - 曼波是中文角色音，念英文不行。
  - 怪读法写 `say`，比如「T X S zero five zero six plus zero five six」「N G C ten sixty-eight」。
- **anchors.json**：每个中文锚点对应英文口播里**同一个意思出现的那个词**。
  - 比较时两边都转小写、去空格和标点，所以 light-year、didn't 都能直接写。
  - 尽量让英文句子的语序和中文一致，比如「进了身体…两种药」写成「Once inside the body, … two completely different drugs」。语序颠倒，画面事件的先后也会跟着颠倒。
  - 数字锚点用阿拉伯数字（「87」不写「eighty-seven」）。TTS 的逐词文本是字面写法。
- **strings.json**：画面文字。
  - **英文平均比中文宽 2–3 倍**。横版药丸标签 ≤25 字符，竖版 ≤18；标题、引语要缩字号（走 replace.json）。
  - 中英同名（名牌上「卡尔·戴瑟罗斯 / Karl Deisseroth」）会重复显示：把英文副行置空，或改成 `en !== name` 才画。
  - 字形：黑体子集（GB2312）没有 ü、³、β、↔、–，也没有 ≠、≤。写 Wurzburg、cubic km、Beta、and、-。build 前用 fontTools 查一遍 cmap（见下）。
  - 拼接句（授奖词由几段字串拼起来、中间一段高亮）：按英文语序重新分配各段，空段写一个空格 `" "`（空字符串会被当成没译）。
  - 图片文件名、路径写 `"-"`（保持原样）。
- **replace.json**：模板字符串（`` `第 ${i} 次` ``、`` `${d} 米` ``）、字号、坐标、整句替换。按英文代码匹配，因为它在翻译之后才执行。
- 代码里写死的 `'<film>/…'` 资源路径（实拍帧索引、图片）build 会自动改成 `<film>_en/`。

```python
from fontTools.ttLib import TTFont; import json
cm = set(TTFont('scripts/engine/lib/fonts/NotoSansSC-500.woff').getBestCmap())
print({ch for v in json.load(open('英文版/strings.json')).values() for ch in v if ord(ch) not in cm})
```

## 外挂 CC 字幕（YouTube 上传用，硬性要求）

英文版除了烧录字幕，还要另出一份 SRT 外挂字幕，跟成片一起交付，上传 YouTube 时作为 CC 字幕（English）。

为什么要单独出：烧录字幕的切法是给画面用的（一行、按画面宽度切，横版约 60 字符，竖版约 34 字符），不符合 CC 规格。外挂字幕的用途是：
- 观众可以开关；
- YouTube 用它做自动翻译和搜索；
- 无障碍。

```bash
cd projects/<slug>/音频_en && python subs.py <film>_en --cc "<英文成片名>"    # → 成片/<英文成片名>.en.srt
```

规格（`subs_en.py --cc` 已按此生成，不动烧录字幕的时间轴）：
- UTF-8，标准 SRT（`HH:MM:SS,mmm`），文件名带语言后缀 `.en.srt`，和成片同名。
- 每条最多 2 行、每行 ≤42 字符；在最接近中点、两行都放得下的词边界折行。
- 每条约 1–7 秒，条与条不重叠（间隔 ≥40 ms）。
- 按句断：句号、问号、感叹号优先，长句在逗号处断；保留完整标点和大小写。
- 写字面文本，不写 `say` 的念法：写 TXS 0506+056，不写 T X S zero five…
- 时间来自 TTS 逐词时间戳，从第一个词开口开始。英文版加了片头标题镜（LEAD）的，时间已经含 LEAD，不用再偏移。

交付时：
- **SRT 本身要检查**：用文本编辑器打开抽查。最长行 ≤42 字符、没有空条、首条时间和开口对得上；脚本会打印条数、最长行和时长范围。
- **跟用户确认上传哪个版本**：画面已经有烧录字幕，再开 CC 会出现两层字。要么上传烧录版、CC 默认关（只给搜索和翻译用），要么另出一个不烧字幕的 YouTube 版（段落表外面包一层 `window.NO_SUBS = true` 渲染，同 `_cover` 的做法）。

## 封面

每支英文版配一张封面：横版 1920×1080，另出 1280×720 缩略图；竖版 1080×1920，另出 720×1280。用 `scripts/make_cover.py`，背景是一张干净的片中画面（不带字幕）。
- 取背景帧：段落表外面包一层 `window.NO_SUBS = true`（存成 `eras_<film>_en_cover.js`，渲完删掉），再 `render.py --stills`，挑镜头开头 0.5–1 秒、标签还没弹出来的时刻。
- kit 没有 `NO_SUBS` 开关的，用 replace.json 给字幕函数加一句 `if (window.NO_SUBS) return;`。
- 有片头标题卡的竖版片，直接用标题卡那一帧，不再叠第二个标题（例：化学奖）。

```bash
python .claude/skills/vertical-science-video/scripts/make_cover.py 渲染/cover_cand/t042.60.png 成片/Cover_EN \
  --title "Hunting|*Ghosts*|Under the Ice" --badge "2026 NOBEL PRIZE IN PHYSICS" --kicker "A telescope made of a cubic kilometer of ice" --side left --shift 420
```

## 检查

- 每镜末帧拼表看一遍。英文版最常见的问题：
  - 药丸、旁注出右边界；
  - 标题逐字出现，没打完就切镜（stagger 调小、字号调小）；
  - 两个标签挤在一起；
  - 中英名字重复。
- 实拍视窗在 `--stills` 里是占位框（由 `window.prepare` 预载）。**全片渲完要抽实拍镜头的帧确认真有画面**：第一次就是因为 `uses.json` 路径写死成中文版，整片都是占位框。
- 中文版的 `glyphcheck.js` 不只是查字形，还可能挂着启动钩子（光遗传学那支在这里调 `N.hookPrepare()` 打开实拍预载）。build 现在会拷它、把 `U.assertGlyphs(` 换成空操作，不再整个丢掉。
- 实拍片的帧窗口按镜头时间抽：英文时间轴变了，要用 `tools/footage_en.py`（读 `<film>_en` 的时间轴）重抽。
